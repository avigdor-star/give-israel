# Retired files

## admin.html

This was the admin dashboard at giveisrael.charity/admin.

It ran entirely on the Supabase database — login, viewing suggestions,
publishing charities, editing Hebrew, the Featured/Partner toggles, deleting.
When Give Israel moved off Supabase (16 Aug 2026), it stopped being able to
work, so it was taken off the live site.

It is kept here only for reference. It is NOT deployed and it will NOT run.

To add or edit a charity now: edit `public/data.js` and push to GitHub.
