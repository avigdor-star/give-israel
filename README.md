# Give Israel

The most comprehensive directory of Israeli charities. Browse by category, search by name, and donate directly.

- **60 verified charities** across 15 categories
- **Hebrew and English** with full right-to-left support
- **Real-time search** and category filtering
- **Community submissions** — the "Suggest a Charity" button is a plain email link, so anyone can email a suggestion in
- No database — all data lives in `public/data.js`
- Static site on Vercel — no build step, no backend, no environment variables

## URLs

- **Main site**: giveisrael.charity
